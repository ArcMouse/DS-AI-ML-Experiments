# 🧪 AI/Data Science Experiments

A dumping ground for AI/ML and data science projects that serve no real purpose beyond "I wanted to see if I could build this." Nothing here is production-ready, nothing here is meant to be. If it works, that's a bonus. If it's useless, that was the point.

## Why this repo exists

Not every project needs a mission. Some of these are here to learn a concept, some are here because a random 2am idea seemed funny, and some are here just to poke at a library or dataset and see what happens. Consider this a lab notebook, not a portfolio.

## Ground rules for this repo

- **No production code.** If something here turns out to be genuinely useful, it gets promoted to its own real repo — not kept here.
- **No cleanup guilt.** Half-finished notebooks and dead-end experiments are allowed to just sit here forever.
- **Every project gets its own folder** with whatever minimal notes future-me needs to remember what past-me was trying to do.
- **Datasets aren't committed** unless they're tiny — large `.csv`/data files should be `.gitignore`'d and noted in each project's own README with where to get them.

*If you're reading this months later wondering why you built any of this: you were curious. That was reason enough.*
